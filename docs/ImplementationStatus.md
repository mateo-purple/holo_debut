# 仕様と実装の照合

**2026-10-31時点で、A段階も完成とは判定していません。** 遊べる完成版として説明した以前の案内は不正確でした。GitHubで配布しているのは、下記の未達事項を含む開発途中のUnityプロジェクトです。

「コードあり」はUnity上で動作確認済みという意味ではありません。.NETのテストは純粋な計算・状態遷移を検証するもので、物理・シーン・UI・ビルドの代わりにはなりません。

## B～D段階

基本仕様v0.3の02節ではこれらは後続段階ですが、**現状実装していない機能**です。データの一部を持つことと、機能が遊べることを区別します。

| 段階 | 未実装 |
| --- | --- |
| B | 4ジャンルの通常配信マス、案件の受諾・辞退、定期収入、借金と救済・独走調整、丁半等の賭け受付と精算、てぇてぇの関係値・倍率・おすそ分け、2～3人コラボ |
| C | 30・60・90番の全員コラボ開催と中断復帰、サイコロチャレンジ等のミニゲーム、順位報酬 |
| D | 配信向けお題モード、オンライン対戦・ホスト確定・同期・ロビー等 |

ゲーム・雑談・歌・ASMRの技能値をPlayerStateに持ちますが、現状の通常企画として動くのは「ゲーム配信」だけです。30・60・90番はチェックポイントIDのみで、イベントを開催しません。将来用のID・参照・インターフェースだけを実装済み機能とは数えていません。
